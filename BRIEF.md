# Линия — implementation brief

One personal VPS, existing NaiveProxy, public-IP TLS, phone setup, Happ and v2Ray subscriptions, owner-issued access, quota, expiry, revocation, real counters, Russian copy. These are the subject inventory.

The page proves a personal link is enough by letting a recipient open that link and import an actual subscription. The owner manages real users in a separate authenticated surface.

Landing argument: a private VPN for your devices (personal link entry); installation uses an ordinary compatible client (platform chooser and real install destinations); access has an owner and finite limits (personal connection page); the link is revocable (honest help answer).

Provisional copy: "VPN для своих". "Одна персональная ссылка для Happ и v2Ray. Откройте её на устройстве и добавьте подключение." Primary action: "Открыть доступ". Supporting sections: "На любом устройстве", "Как подключиться", "Вопросы". No pricing, synthetic testimonials or fictitious latency.

Visual worlds considered: library loan slip; rail wayfinding; modern correspondence stationery; print studio route map; personal membership pass; field guide editorial spreads; restrained music-player interface. A physical personal pass and a clear product fragment suit one-issued-link access. The page must remain an immediately useful product, not a technical-console costume.
